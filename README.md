# 1 ใน 720

เกมจำลองชีวิตนักเรียนโรงเรียนประจำ เกิดมาเป็นนักเรียนสุ่ม 1 คนใน 720 คน แล้วเล่นตั้งแต่ ม.1 ถึง ม.6 จนจบ

**เล่นได้เลย:** https://cjpsms.github.io/one-in-720/

A browser life sim of a Thai science boarding school: you are born as one random student out of 720, and play from M.1 to M.6 until graduation.

## เกี่ยวกับเกม

ฉากหลังคือโรงเรียนวิทยาศาสตร์จุฬาภรณราชวิทยาลัย พิษณุโลก (PCSHSPL, Princess Chulabhorn Science High School Phitsanulok)

- เกิดเป็นนักเรียนสุ่ม เพศสุ่ม ห้อง 1-4 ใน ม.1 ตามผลสอบ
- ห้องจัดใหม่ทุกปีตามเกรดของปีนั้น และจบที่ ม.6
- ด่าน ม.3 ไป ม.4 รับ 144 คนจากทุกคน สอบไม่ติดต้องเลือกว่าจะไปต่อหรือหยุดเรียน
- อยู่หอพัก กลับบ้านทุก 2 สัปดาห์ (จุดเซฟ) มีค่าตัง ค่าขนม และขอเงินพ่อแม่ได้
- ตารางเรียนจริงจังจันทร์-ศุกร์ มีโรงอาหาร สหกรณ์ ชุมนุม กีฬาสี งานลอยกระทง งานราตรี
- กิจกรรมหลายอย่างเป็นมินิเกมให้เล่นจริง

## ไม่เกี่ยวข้องกับโรงเรียน

นี่เป็นโปรเจกต์ส่วนตัวที่ทำเล่นๆ **ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจากโรงเรียนแต่อย่างใด**
ตัวละคร ครู และนักเรียนทุกคนในเกม **สมมติขึ้นทั้งหมด** (ชื่อสุ่ม) ถ้าไปตรงกับคนจริงถือเป็นความบังเอิญ
This is an unofficial fan project. It is not affiliated with or endorsed by the school. All characters, teachers and students are fictional.

## รันเอง

เป็นเว็บ static (JS ES modules ล้วน ไม่มี build ไม่มี dependency) แต่ต้องเปิดผ่าน http ไม่ใช่ `file://`

```bash
node serve.js          # http://127.0.0.1:4026
npm test               # เช็กตรรกะของ sim
```

หรือใช้เซิร์ฟเวอร์ static อะไรก็ได้ เช่น `python3 -m http.server`

## โครงสร้าง

- `src/` เอนจินจำลอง (`sim.js`, `rooms.js`, `money.js`, ...), `src/ui/` หน้าจอและมินิเกม, `src/data/timetable/` ตารางเรียน ม.1-ม.6
- `DESIGN.md` ร่างดีไซน์, `docs/` สัญญาระหว่างโมดูล
